# Cybersecurity2
Second part of the DIO class about cybersecurity challenges

Nessa segunda parte da aula com desafios foram mostrados como fazer criptografia e descriptografia de arquivos, bem como captura de entrada de digitos do teclado.

Serão criados os códigos python para criptografia, descriptografia, e um keylogger(captura de teclas) nesse repositório, bem como um arquivo de texto para teste de criptografia.

O keylogger devera criar um arquivo log.txt, não será incluído o envio para email, mas deve ser notado a possibilidade dessa opção, também deve ser notado a possibilidade de rodar em background, na aula foi demonstrado o uso da extensão pyw, mas vale lembrar que isso implica o uso em uma máquina windows, pelo menos foi explicado dessa forma no curso.
